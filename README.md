# 🌍 worldmonitor — 社会热点结构化入口

每天自动抓取全网热点，分板块整理 + AI 评价分析，通过飞书文档 + 消息推送。

## 📋 板块划分

| 板块 | 覆盖范围 |
|------|----------|
| 🤖 科技/AI | 大模型、互联网公司、产品发布、技术突破、行业融资 |
| 🏘️ 社会民生 | 热搜事件、民生政策、公共安全、教育就业、年轻人话题 |
| 💰 财经/股市 | 宏观经济、A股/美股、行业动态、公司财报、政策影响 |
| 🌍 国际/时事 | 国际局势、地缘政治、全球大事、中外关系 |
| 🎭 文娱/体育 | 影视综艺、明星动态、体育赛事、游戏电竞 |

## 🔄 每日流程

1. **数据采集**：抓取微博热搜、知乎热榜、百度热搜、抖音热点等
2. **去重合并**：跨平台去重，识别同一事件的不同表述
3. **板块分类**：将热点自动归入对应板块
4. **AI 评价分析**：对每个热点给出影响评估、趋势判断和关注点
5. **生成日报**：输出为飞书文档，分板块结构化展示
6. **消息推送**：飞书私聊发送摘要 + 文档链接

## ⚙️ 配置说明

### 板块关键词映射

见 `config/sections.yaml`，每个板块配置了匹配关键词，用于自动分类热点。

### 推送方式

- **飞书文档**：每日生成一篇独立文档，包含完整分析
- **飞书消息**：私聊发送摘要卡片，含文档直达链接

## 🚀 快速开始

```bash
# 安装依赖
pip install -r requirements.txt

# 运行一次完整流程
python scripts/monitor.py --run-once

# 仅抓取热点不推送
python scripts/monitor.py --fetch-only
```
