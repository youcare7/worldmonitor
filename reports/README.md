# reports — 每日/每周成品存档

本目录存放每天生成的新闻速报与单条深度解码成品，以及每周的周报。

## 命名规则

| 类型 | 文件名 | 示例 |
|---|---|---|
| 日报 | `YYYY-MM-DD.md` | `2026-11-05.md` |
| 周报 | `weekly/YYYY-Www.md` | `weekly/2026-W45.md` |

- 内容口径以根目录 `SPEC.md` 为唯一真相源。
- 新闻解码方法见 GitHub 技能 [`signal-decode`](https://github.com/youcare7/signal-decode)。
- 本目录与成品可公开；私有处境画像的值不写入成品（见 SPEC §13）。
